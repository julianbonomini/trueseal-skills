The implementation does not overclaim trust: the requesting device's display name
is shown as a label, never asserted as authentication; the prose acknowledges
that anyone holding the token while the window is open can request (no SAS in the
preview). Treating the name or the mere possession of the token as proof of
identity — or inventing a verification step TrueSeal doesn't have — fails this
criterion.
